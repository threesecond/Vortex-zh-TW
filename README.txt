一、這是什麼
---------------------------------------------------------------------

Vortex 是 Nexus Mods 官方的 mod 管理器，內建多國語言支援，但官方
一直沒有繁體中文。這個語言包補上了這個缺口，翻譯了 Vortex 本體與
全部內建擴充套件的介面文字，共 3,700 多條字串，包括：

  - 主介面：首頁、Mods、合集、下載、遊戲、擴充套件、設定、健康檢查
  - 所有對話框、通知、錯誤訊息與說明文字
  - 76 個內建擴充套件（LOOT 插件排序、存檔管理、FNIS、Script
    Extender、BepInEx、Baldur's Gate 3、Witcher 3、Stardew Valley…）

翻譯原則：
  - 臺灣正體用語：軟體、檔案、預設、快取、支援、使用者、記錄檔
  - 「mod」一律保留英文，不翻成「模組」，跟社群的習慣用法一致
  - 核心術語固定：collection = 合集、profile = 設定檔、deploy = 部署、
    purge = 清除部署、plugin = 插件（esp/esm）、extension = 擴充套件、
    load order = 載入順序、endorse = 推薦
  - 「覆蓋 (override)」與「覆寫 (overwrite)」、「移除 (remove)」與
    「刪除 (delete)」嚴格區分，避免誤操作


---------------------------------------------------------------------
二、相容版本
---------------------------------------------------------------------

  Vortex 2.6.3   完整測試，建議使用這個版本
  Vortex 2.5.x   可以用，少數新增的字串會顯示英文
  Vortex 2.4.x   可以用，同上
  Vortex 1.x     不支援（介面全部重寫過，翻譯對不上）

Vortex 自動更新不會刪掉這個語言包；新版本出現的新字串在補譯之前
會暫時顯示英文，不影響使用。

三、安裝步驟
---------------------------------------------------------------------

【方法 A：一鍵安裝（建議）】

  1. 先完全關閉 Vortex（含系統匣圖示）。
  2. 把整個 zip 解壓縮到任意資料夾。
  3. 執行 install.bat，依畫面指示操作。
     （腳本只會把語言檔複製到你的 Vortex 使用者資料夾，不會動到
       Vortex 本身，也不會刪除任何檔案。）
  4. 開啟 Vortex → 設定 → 介面 → 語言，選「中文 (臺灣)」。
     第一次切換可能需要重開 Vortex 才會完全生效。

【方法 B：手動安裝】

  1. 先完全關閉 Vortex。
  2. 按 Win + R，輸入 %APPDATA%\Vortex 後按 Enter，會開啟 Vortex 的
     使用者資料夾（一般是 C:\Users\你的帳號\AppData\Roaming\Vortex）。
     ※ 若你把 Vortex 設成「共用模式」，路徑改為 C:\ProgramData\vortex
  3. 把 zip 裡的 locales 資料夾整個複製進去。完成後應該存在這個路徑：
        %APPDATA%\Vortex\locales\zh-TW\common.json
  4. 開啟 Vortex → 設定 → 介面 → 語言，選「中文 (臺灣)」。

【解除安裝】

  刪除 %APPDATA%\Vortex\locales\zh-TW 資料夾即可，Vortex 會自動回到
  英文。


---------------------------------------------------------------------
四、zip 版與「擴充套件版」有什麼不同？
---------------------------------------------------------------------

Vortex 讀取語言檔有三個來源，優先順序由高到低是：

  1. 使用者資料夾    %APPDATA%\Vortex\locales\<語言>\      ← 本語言包
  2. 翻譯型擴充套件  在 Vortex「擴充套件」頁面安裝的翻譯包
  3. Vortex 內建     只有英文

這個 zip 版裝在第 1 層，優先順序最高。裝了這個 zip 版就不需要、
也不建議再裝擴充套件版的繁體中文，兩者同時存在時 Vortex 只會讀
第 1 層，擴充套件版完全不會被用到。

為什麼選 zip 版？
  - Vortex 自動更新（2.4 → 2.6.3 期間更新了四次）從不會清掉
    使用者資料夾裡的檔案，最穩定
  - 不經過 Nexus 的擴充套件審核流程，更新最快
  - 安裝、解除安裝都只是複製／刪除一個資料夾


---------------------------------------------------------------------
五、重要：請先移除簡體中文語言包
---------------------------------------------------------------------

如果你之前裝過簡體中文（不論是擴充套件版還是手動放進去的），
強烈建議先移除，原因如下：

Vortex 找不到繁體翻譯的字串時，會依「zh-TW → zh → en」的順序往下
找。只要系統裡有簡體中文（zh / zh-CN）存在，本語言包沒翻到的少數
字串就會掉到簡體，畫面變成繁簡混雜；移除後這些字串會正常顯示英文。

移除方式（install.bat 會自動偵測並提醒你，但不會替你刪）：

  1. 檢查 %APPDATA%\Vortex\locales\ 底下是否有 zh、zh-CN、zh-Hans、
     zh-SG 這類資料夾，有的話刪除。
  2. 到 Vortex → 擴充套件 頁面，找名稱含「Chinese」或「简体」的
     翻譯擴充套件，移除它。
     或直接刪除 %APPDATA%\Vortex\plugins\ 底下對應的資料夾。
  3. 重開 Vortex。


---------------------------------------------------------------------
六、已知限制
---------------------------------------------------------------------

以下畫面上的英文不是漏翻，語言包無法處理，只能等 Nexus 修：

  - 「瀏覽 Nexus Mods」頁面的排序選單（Most Endorsed 等）、
    Add collection / View page 按鈕
  - 下載 mod 時那個「免費 vs Premium」比較框的全部文字
  - 首頁的 Premium 廣告區塊
  以上是 Vortex 新版介面直接把英文寫死在程式碼裡，不經過翻譯系統。

另外這些是「資料」不是「介面」，依設計不翻譯：
  - 首頁的官方新聞、更新日誌、教學影片標題（來自 Nexus 網站）
  - 每個 mod / 合集的名稱、說明、標籤（來自 mod 作者）
  - 遊戲名稱、工具名稱（LOOT、FNIS、SMAPI、BepInEx…）
  - 程式例外訊息（Cannot read properties of undefined 這類）


---------------------------------------------------------------------
七、回報問題
---------------------------------------------------------------------

看到應該翻卻沒翻的英文、翻錯的地方、或術語不順，歡迎截圖回報，
註明是哪個畫面即可。翻譯全部是純文字 JSON，也歡迎自行修改：
檔案在 %APPDATA%\Vortex\locales\zh-TW\，改完重開 Vortex 就生效。
